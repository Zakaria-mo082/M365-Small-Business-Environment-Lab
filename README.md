# Small Business Microsoft 365 Environment Lab

## Project Overview
Designed, deployed, and administered a cloud-only Microsoft 365 tenant simulating a small business environment for 20+ users. This project demonstrates hands-on expertise in Microsoft Entra ID user provisioning, departmental group and Teams architecture, role-based access control (RBAC), and OneDrive administration. Practiced real-world security and lifecycle management by executing emergency account isolation controls—blocking compromised sign-ins, revoking active sessions, preserving user data, and deprovisioning licenses during offboarding procedures.

## Core Admin Scenarios Implemented
- **Identity & Access Management:** Provisioned 20+ enterprise users with Microsoft 365 Business Premium licenses and assigned role-based access control (RBAC) to enforce least privilege.
- **Departmental Architecture:** Built segmented Microsoft 365 Groups and Teams for HR, Finance, IT, Management, and Marketing to enforce data isolation and granular membership controls.
- **Dynamic Communications:** Configured Dynamic Distribution Lists to automate executive communication workflows without manual group maintenance.
- **Security & Lifecycle Administration:** Executed emergency account isolation controls (session revocations and sign-in blocks), configured OneDrive storage quotas (1024 GB), and validated soft-delete user recoveries.
